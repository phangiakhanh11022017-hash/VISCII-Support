# 🇻🇳 VISCII-Support

A lightweight, single-header C++ library (`viscii_ascii.h`) for encoding, decoding, and processing Vietnamese text in the **VISCII** character set (RFC 1456).

## 📂 Repository Structure

```text
VISCII-Support/
├── viscii_ascii.h   # Main single-header library
├── Example.cpp      # Sample usage program
└── README.md        # Documentation
```

## ⚙️ Installation & Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Include in your project:**
   Copy `viscii_ascii.h` into your project and include it:
   ```cpp
   #include "viscii_ascii.h"
   ```
3. **Compile the example:**
   ```bash
   g++ -std=c++17 Example.cpp -o example
   ./example
   ```

*(Note: Specific function names and internal implementations can be referenced directly from `viscii_ascii.h` and `Example.cpp` within the repository.)*
